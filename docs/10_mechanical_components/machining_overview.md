## 2. 加工方式快速选型决策树

当你拿到一个零件设计，用以下决策树选出最适合的加工方式：

### 2.1 第一步：零件属于哪种几何类别？

零件形状
├─ 回转体（轴、套、法兰、螺纹）
│   └─ 精度要求？
│       ├─ 一般（IT7~8） → 车削（精车）
│       ├─ 高（IT5~6） → 车削+磨削（外圆磨）
│       └─ 有色金属（铝/铜）高精度 → 精细车（无需磨）
│
├─ 非回转体（板、支架、壳体、曲面）
│   ├─ 主要为平面、垂直壁、槽
│   │   ├─ 单件/小批量 → 铣削（3轴立铣）
│   │   └─ 批量大（>100） → 考虑注塑或压铸
│   ├─ 包含复杂3D曲面
│   │   ├─ 曲率平缓 → 3轴+球头刀（分层加工）
│   │   ├─ 曲率陡峭/倒扣 → 5轴铣削（成本高）或EDM
│   │   └─ 表面要求镜面 → 球头刀精铣+手工抛光
│   └─ 薄板类（厚度≤6mm）
│       ├─ 金属 → 激光切割（最快最便宜）
│       ├─ 厚板（>25mm）或热敏感材料 → 水刀切割
│       └─ 内角需要直角 → 线切割（慢但精确）
│
└─ 含有深窄槽、微小孔、锐角内角
    ├─ 淬硬钢（HRC>40）复杂型腔 → 电火花成型
    ├─ 直通形状（冲头、异形孔） → 线切割
    └─ 极小孔（<0.5mm） → 电火花穿孔


### 2.2 第二步：根据精度和表面质量缩小范围

| 要求精度（IT） | 表面粗糙度 Ra（μm） | 可选加工方式 | 成本相对值 |
|----------------|----------------------|--------------|------------|
| IT11~13 | 12.5~50 | 粗车、粗铣、钻孔 | 1 |
| IT8~10 | 3.2~6.3 | 精车、精铣、扩孔 | 2 |
| IT7~8 | 0.8~1.6 | 精车（钢）、精铣、铰孔 | 3 |
| IT6~7 | 0.2~0.8 | 磨削、精细车（铝） | 5 |
| IT5~6 | 0.05~0.2 | 研磨、抛光 | 10+ |

### 2.3 第三步：考虑生产数量

- **单件/原型（1-5件）**：CNC铣削/车削 + 3D打印（塑料/蜡模）快速验证。尽量避免开模、EDM（成本高）。
- **小批量（10-100件）**：CNC加工为主，可考虑线切割（如果有薄板异形孔）。成本优化：合并特征、减少换刀。
- **大批量（>500件）**：注塑、压铸、粉末冶金等成型工艺（不在本文讨论范围）。

## 3. 面向制造的设计（DFM）核心原则

以下原则适用于所有机械加工，违反任何一条都会显著增加成本或导致零件不可制造。

### 3.1 壁厚：避免过薄和突变

**基本规则**：
- 金属件最小壁厚：铝合金/碳钢 ≥0.8mm（建议≥2mm）；不锈钢/钛合金 ≥1.2mm
- 塑料件最小壁厚：≥1.2mm（建议≥2mm）
- 壁厚变化处必须设计平滑过渡，斜度≥30°，避免直角台阶

**原因**：
- 薄壁加工时因切削力变形，导致尺寸超差和振纹
- 壁厚突变导致残余应力集中，热处理后翘曲

**设计示例**：
- 错误：一个区域壁厚1.5mm，相邻区域8mm，中间90°台阶
- 正确：从1.5mm到8mm用10mm长的斜面过渡，斜度约33°

### 3.2 内角与圆角（铣削、线切割）

**基本规则**：
- 立铣刀加工的内角最小圆角半径 R ≥ 刀具半径 + 0.2mm（常用R1或R2）
- 球头刀加工的内角R ≥ 球头半径 × 1.2（防止过切）
- 轴肩、悬臂根部必须设计应力圆角 R ≥ 0.5mm（疲劳寿命关键）
- 外部锐边一律倒角 C0.5~C1（安全+去毛刺）

**原因**：
- 铣刀是圆柱体，无法切出绝对直角，留下圆弧痕迹
- 直角内角处应力集中，易疲劳断裂

**特殊处理**：
- 若设计必须为直角（如模具配合面），须改为线切割或电火花，成本增加3-5倍

### 3.3 孔径与孔深

**基本规则**：
- 最小钻孔直径：≥3mm（≤1mm微孔需电火花穿孔）
- 盲孔深度 ≤ 3 × 孔径（例如Φ5mm盲孔深≤15mm）
- 通孔深度 ≤ 5 × 孔径（更深需深孔钻，成本高）
- 螺纹深度 ≤ 3 × 公称直径（如M6螺纹深度≤18mm）
- 斜面上钻孔前必须设计垂直于轴线的平台（直径≥孔径+2mm）

**原因**：
- 深孔钻头刚性差，易偏斜、断裂；排屑困难
- 螺纹过深：丝锥易断，且螺纹受力有效长度仅前3个螺距

**常用螺纹底孔参考**：
| 螺纹规格 | 底孔直径（钻头） | 推荐攻丝深度 |
|----------|------------------|--------------|
| M3 | Φ2.5 | ≤9mm |
| M4 | Φ3.3 | ≤12mm |
| M5 | Φ4.2 | ≤15mm |
| M6 | Φ5.0 | ≤18mm |

### 3.4 刀具可达性与夹持设计

**基本规则**：
- 所有被加工表面必须能从刀具轴线方向直线接近（3轴加工）
- 深腔（槽）深度 ≤ 4 × 刀具直径（例如Φ10立铣刀加工深度≤40mm）
- 避免“倒扣”结构（即刀具无法进入的底部收缩区域）
- 为薄壁件设计工艺夹持耳或凸台（加工后切除）

**原因**：
- 刀具悬伸过长会产生振动，影响精度和寿命
- 倒扣只能用5轴或EDM，成本剧增

**设计技巧**：
- 在零件非功能面上增加夹持块（厚度≥5mm，宽度≥10mm），加工后铣掉
- 对于薄板类零件，设计成多个零件共用一块毛坯板，中间留连接筋，加工后切断

### 3.5 公差标注：只收紧必要位置

**基本规则**：
- 一般尺寸：采用GB/T 1804-m（±0.1~0.2mm）
- 配合尺寸：标注公差，例如 `Φ10H7`（+0.015/0）或 `Φ10g6`（-0.005/-0.014）
- 关键平面：标注平面度、平行度，例如 `平面度 0.02`
- 避免“无差别高公差”——所有尺寸都标±0.01会导致成本翻倍

**工程经验**：
- 轴承安装位：轴颈IT6，孔IT7
- 一般螺栓过孔：IT12~13（±0.1~0.2mm）
- 非配合面自由尺寸：IT13~14（±0.2~0.5mm）

### 3.6 零件刚性设计

**基本规则**：
- 避免“L”形薄壁结构（易变形）→ 改为“T”形或加筋
- 长径比大于10的轴类零件，在图纸上要求采用“两顶尖”装夹
- 薄底板（厚度<5mm）应设计加强筋（高度×宽度=3:1，间距≤50mm）

**原因**：
- 刚性不足导致加工时零件颤动，表面呈“水波纹”
- 夹具无法提供足够支撑时，需设计工艺支撑

### 3.7 不同材料的可加工性提示

| 材料 | 可加工性等级 | 注意事项 |
|------|--------------|----------|
| 铝合金（6061,7075） | ★★★★★ | 易切削，但热膨胀系数大；薄壁易变形 |
| 低碳钢（Q235, 45钢） | ★★★★ | 通用性好，调质后硬度适中 |
| 不锈钢（304,316） | ★★★ | 加工硬化严重，需锋利刀具和低速 |
| 钛合金（TC4） | ★★ | 难加工，成本高；需要专用刀具 |
| 黄铜/铜 | ★★★★★ | 易产生毛刺，注意倒角 |
| 工程塑料（POM, ABS） | ★★★ | 铣削可做，需注意散热；激光切割冒烟 |

## 4. 各加工方式详细对比表

| 加工方式 | 典型形状 | 可达精度（IT） | 经济粗糙度（μm） | 相对成本（1-10） | 最小特征尺寸 | 设计禁忌 |
|----------|----------|----------------|-------------------|------------------|--------------|----------|
| **车削** | 轴、套、螺纹 | 7~8（精车） | 0.8~1.6 | 2 | 轴径≥1mm | 非回转体；无中心孔 |
| **铣削（立铣刀）** | 平面、槽、轮廓 | 7~8 | 0.8~1.6 | 3 | 槽宽≥1mm | 内角直角；深腔>4D |
| **铣削（球头刀）** | 3D曲面 | 8~9 | 0.4~0.8（残留纹） | 5 | 曲率半径≥1mm | 曲率过陡；不标注残留高度 |
| **面铣** | 大平面 | 8~9 | 1.6~3.2 | 2 | 平面面积≥10×10mm | 平面有凸起 |
| **钻孔** | 圆孔 | 11~13 | 12.5~50 | 1 | 孔径≥3mm | 深孔；斜面孔 |
| **铰孔** | 高精度圆孔 | 7 | 0.2~1.6 | 2 | 孔径≥4mm | 铰前钻孔余量不足 |
| **磨削（外圆）** | 淬硬轴 | 5~6 | 0.08~0.8 | 6 | 轴径≥5mm | 未预留磨削余量 |
| **磨削（平面）** | 高平面度 | 5~6 | 0.08~0.8 | 6 | 面积≥20×20mm | 无基准面 |
| **线切割** | 异形通孔、冲头 | ±0.005mm | 0.2~0.4 | 7 | 最小锐角≥0.1mm | 无穿丝孔；非导电材料 |
| **激光切割** | 2D薄板 | ±0.03mm | 切缝粗糙 | 1 | 孔径≥板厚 | 尖角；内角R<板厚 |
| **水刀切割** | 厚板/热敏感 | ±0.1mm | 3.2~6.3 | 4 | 孔径≥2mm | 小特征过切 |

## 5. 常见加工缺陷、原因与设计预防

| 缺陷 | 常见原因 | 设计上如何预防 |
|------|----------|----------------|
| 表面振纹（水波纹） | 刀具/工件刚性不足 | 避免薄壁深腔；加筋；缩短刀具悬伸 |
| 尺寸超差（孔偏） | 钻头滑移 | 设计中心孔；斜面铣平台 |
| 锐边毛刺 | 铣削/车削产生 | 图纸标注“去毛刺”；设计倒角 |
| 螺纹烂牙 | 底孔偏小或丝锥断裂 | 按标准底孔；螺纹深度≤3d |
| 薄板切割变形 | 内应力释放 | 对称切割路径；预留连接筋 |
| 热处理后弯曲 | 壁厚不均 | 均匀壁厚；对称结构 |
| 残留台阶（曲面） | 球头刀步距过大 | 标注允许残留高度；留抛光余量 |
| 尖角处过切 | 水刀/激光束滞后 | 避免尖锐外角；加R≥1mm圆角 |

## 6. 成本与周期估算（粗略参考）

对于CNC加工零件，以下因素主导成本（从高到低）：

1. **材料**：钛/不锈钢 > 铝合金 > 塑料
2. **精度要求**：IT7以上需磨削或精铣，工时翻倍
3. **复杂程度**：曲面 > 多面 > 简单2.5D
4. **装夹次数**：每多一次装夹，增加30%工时和误差
5. **刀具更换**：频繁换刀（如不同直径孔）增加编程和等待时间
6. **表面处理**：氧化、喷涂等额外工序

## 7. 设计检查清单（打印贴墙）

出图前逐项确认：

### 7.1 通用项
- [ ] 壁厚是否≥2mm（金属）或≥1.2mm（塑料）？有无突变？
- [ ] 所有内角是否已加圆角（R≥1mm）？外角是否倒角（C0.5）？
- [ ] 孔深是否≤3×孔径？螺纹深度≤3×公称直径？
- [ ] 斜面孔是否设计了平台？
- [ ] 是否存在刀具无法进入的倒扣或深腔（深度>4×刀具直径）？
- [ ] 薄壁件是否预留了工艺夹持凸台？
- [ ] 公差标注是否区分关键面与自由尺寸？

### 7.2 按加工方式专项
- [ ] 回转体零件两端是否设计了中心孔？
- [ ] 铣削曲面是否标注了允许的残留高度？
- [ ] 需要磨削的零件是否标注了“热处理后磨”和磨削余量？
- [ ] 线切割零件是否设计了穿丝孔？材料是否导电？
- [ ] 激光切割钣金内角R≥板厚？有无尖锐外角？

## 8. 参考标准与资源

- **GB/T 1804-2000** 一般公差 未注公差的线性和角度尺寸的公差
- **GB/T 1184-1996** 形状和位置公差 未注公差值
- **GB/T 5277-1985** 紧固件 螺栓和螺钉通孔
- **机械设计手册（第6版）** 机械工业出版社，第1卷（常用设计资料）和第3卷（机械加工工艺）

> **最后总结**：机械加工设计的关键在于**提前思考加工过程**。壁厚、圆角、孔径、公差、装夹这五个要素做到位，你的零件就成功了一半。当不确定时，用“模拟刀具路径”的思路：想象一把立铣刀或车刀在空间中运动，是否能无障碍地切出所有特征。
